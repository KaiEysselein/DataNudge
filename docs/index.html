WHAT IT DOES

A focused reminder, not another dashboard.

01

Choose your apps

Select launchable apps installed on your phone. Your choices remain local.

02

Watch the connection

See Wi-Fi, mobile data, VPN, Ethernet, Bluetooth networking, or offline status.

03

Receive a nudge

When a selected app opens on mobile data, DataNudge displays a reminder above it.

04

Keep monitoring

User-enabled background monitoring can continue after the main screen is closed.

SET UP ONCE

Android stays in control.

The guided setup explains each permission. Installation, updates, and permission changes always require your action or Android confirmation.

  1. 1Grant notification, Usage Access, and overlay permissions.
  2. 2Select the installed apps you want to monitor.
  3. 3Enable monitoring and let DataNudge run quietly.

DataNudge privacy

Last updated: 3 August 2026

What DataNudge does

DataNudge detects the active connection type and checks foreground app usage events so it can remind the user when a selected app opens while mobile data is active.

Information stored on the device

DataNudge stores monitoring state, selected app package names, setup and disclaimer state, update preferences, and connection-session timing and traffic-counter baselines in its app data on the device. Android backup, restore, device-transfer, or device-management features may also preserve that app data.

Information DataNudge does not read

DataNudge does not read messages, passwords, typed text, media contents, browsing contents, or the screen contents of monitored apps.

Network transmission

DataNudge does not intentionally transmit the selected-app list, foreground usage events, or connection-session data to the developer. Manual and enabled automatic update checks contact GitHub to read published release information. If the user chooses to download an update, DataNudge downloads the selected GitHub release APK into its private cache before asking Android to open the package installer.

Android permissions

DataNudge uses notification permission, Usage Access, display-over-other-apps permission, network-state access, internet access, foreground-service access, boot-completed delivery, and install-unknown-apps access for its user-requested monitoring and update functions.

This page describes the current alpha version and should be reviewed before a public app-store release or after adding analytics, advertising, cloud storage, or third-party data-processing services.

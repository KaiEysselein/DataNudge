# DataNudge

DataNudge is an Android app that reminds the user when selected apps open while the phone is using mobile data.

## Current status

Current development version: **0.0.4.1 alpha**

## Features

- Wi-Fi, mobile-data, VPN, Ethernet, and offline detection
- User-selected app monitoring
- Mobile-data overlay reminders
- Foreground monitoring service
- Start after device restart
- Guided setup wizard
- Local storage of settings

## Build

```powershell
cd "D:\Github\DataNudge"
.\gradlew.bat assembleDebug
```

The debug APK is created at:

```text
app\build\outputs\apk\debug\app-debug.apk
```
